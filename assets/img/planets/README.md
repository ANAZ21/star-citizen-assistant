# Hurston demo textures

These files are used only by the `hurston.html` visual prototype.

- `hurston-surface.webp`, `hurston-normal.webp`, `hurston-clouds.webp`, `hurston-lights.webp`
- Base surface: **Mars 8K texture** from [Solar System Scope](https://www.solarsystemscope.com/textures/), licensed **CC BY 4.0**.
- The base texture was resized, desaturated, tinted toward an industrial brown-grey, and had polar caps darkened to create a Hurston-like stand-in. A normal map, a procedural dust-cloud alpha layer, and a separate city-light map were generated from it.
- These are **not** extracted Star Citizen assets. The planet is a visual approximation for layout/lighting/interaction prototyping.
