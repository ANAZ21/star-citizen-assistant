01 起步：前几小时

星际公民没有传统主线。起步阶段先建立任务循环：接取任务、飞行、完成、结算，再选择下一趟目标。建议优先熟悉基础流程，暂缓购买大型舰船。

选一个出生点

城市特点说明
Area18 · 弧光星商业与船店集中霓虹都市，Astro Armada 船店和装备商店集中，商业设施密集。
New Babbage · 微科科研与观光雪原上的科技城，城市规模较大，轨道交通连接主要区域，Factory Line 船店位于城中。
Orison · 十字军云城观光云层上的平台城市，观光设施集中，平台之间移动耗时较长。
Lorville · 赫斯顿工业企业城公司城，船店、装备商店和地铁齐全，地表雾霾较重。
首次进入游戏：按 F1 打开 mobiGlas，熟悉合同（Contracts）、星图（Map）与库存（Inventory）。建议先完成一单基础快递任务，以掌握完整流程。

第一艘船怎么选

入门包中的极光 MR 与野马 Alpha 均可使用。预算允许时，Avenger Titan（复仇者 泰坦） 是常见的第二阶段选择：8 SCU 货舱、2×S3 与 1×S4 火力，可执行快递、赏金和小型货运任务。

  • 预算有限：极光 MR / 野马 Alpha，优先执行快递任务。
  • 想一艘船多用途：泰坦、游牧者、切割者。
  • 以战斗为主：箭矢、短剑；使用前应确认是否愿意投入时间练习近距空战。

舰船被摧毁后

在空间站或城市太空港找到 ASOP 船舶终端，选择被摧毁的船并提交保险索赔（Claim）。基础索赔需要等待，也可以付费加急。等待时间与船的大小有关。索赔完成后，船会重新出现在终端列表里。

应避免的操作：在 Armistice（禁火）区开火；携带犯罪等级进入 UEE 空间站；将全部资金投入单次货运。

下面是几种常见收入方式，按上手难度从低到高排列。

标准任务循环：接取任务 → 出发前补给 → 完成任务 → 出售货物或交付任务 → 返回站点维修加油 → 接取下一单。量子燃料和医疗用品不应省略。

起步路线

尚未接触飞行的玩家，建议先完成 5–10 单快递，熟悉斯坦顿四个着陆区与主要空间站；随后接取 VLRT / LRT 赏金任务练习战斗。能够稳定完成低阶赏金后，再考虑 ROC 采矿或打捞等需要额外工具的玩法。

03 买船思路

舰船可通过 RSI 官网美元购买（Pledge）或游戏内 aUEC 购买。美元购买支持开发并直接获得舰船；aUEC 需要在游戏内积累。应避免以回本为目标购买不适合自身玩法的舰船。

按预算选船

预算（USD）推荐理由
20–75极光 MR、野马 Alpha、切割者、复仇者 泰坦适合建立基础任务循环；Avenger Titan 是多用途起点。
75–150短剑、弯刀 黑、游牧者、自由职业者、C1 精灵开始覆盖战斗与货运；弯刀 黑兼顾两类任务，适用面较广。
150–300勘探者、秃鹫、星座 仙女座、海盗船、水星、宙斯进入专业玩法或中型多人舰船；需要固定船员。
300+克拉克、C2、回收者、北极星大型船需要团队、补给和固定玩法，不建议作为首艘舰船。
多人舰船说明：星座、克拉克、锤头鲨等舰船需要船员才能发挥完整战斗力与效率。单人操作仅能维持基本飞行，购买前应确认是否有固定队伍。

概念船与 CCU

概念船（Concept）尚未实装，数值与外形可能调整。购买概念船更接近支持开发与预订，无法立即飞行。希望即时游玩时，应优先选择状态为“可飞”的舰船。

官网 CCU（Cross-Chassis Upgrade）可将现有舰船升级为更贵的舰船，仅支付差价，适合先购买小型舰船、后续升级的路线。升级通常不可逆，操作前需确认。

04 地点与航线

斯坦顿拥有 UEE 巡逻、医疗与补给设施，适合熟悉基础任务循环。派罗没有统一法律，空间站由帮派控制，PvP 与伏击较为常见。

区域适合做什么风险
Area18 / Baijini Point买船、买装备、接任务、跑快递低；玩家密集，应避免在禁火区开火。
Yela / Grim HEX黑市、非法任务、PvP高；无 UEE 执法，常有埋伏。
Lyria / DaymarROC 地面采矿中；环境恶劣，需要准备补给与地面载具。
Pyro Gateway → 派罗跨星系、走私、高风险任务极高；跳跃点附近常有伏击。
Checkmate / Ruin派罗黑市、补给、任务极高；帮派控制，玩家冲突频繁。

前 10 小时的一条参考路线

  1. 在 Area18 出生，完成 3–5 单本地快递，熟悉起降与量子航行。
  2. 前往 Baijini Point 接取跨区域任务，并查看船店库存。
  3. 用泰坦或短剑接取 VLRT / LRT 赏金，练习基础战斗与导弹使用。
  4. 积累资金后升级至弯刀 黑或自由职业者，开始中型货运。
  5. 如需其他收入方式，可前往 Lyria 尝试 ROC 采矿；具备条件后再进入派罗。

05 去哪买船、租船、买武器

术语速查

aUEC游戏内货币，用于买船、装备、货物和补给。
SCU标准货舱单位，用来衡量飞船能装多少货。
QTQuantum Travel，量子航行；消耗量子燃料在星系内快速移动。
LZLanding Zone，着陆区，通常指城市或主要据点。
POIPoint of Interest，兴趣点；矿点、残骸、前哨都算。
Crime Stat犯罪等级；越高越容易被 UEE 通缉，可在 Kareah 清除。
Armistice禁火区；在空间站和城市周边开火会被安保攻击。
Claim保险索赔；船被毁后通过 ASOP 终端取回。
CCU跨船升级，用差价把一艘船升级成另一艘。
Jump Point跳跃点；连接两个星系的通道，目前斯坦顿与派罗之间已开放。
Refinery精炼站；把原矿加工成可出售的材料。
Salvage打捞 / 回收；从残骸上剥离材料出售。
